# 标签生成器 — 用户手册与技术文档

语言：[English](USER_GUIDE.md) · [Português (pt-BR)](USER_GUIDE.pt-BR.md) · **简体中文**

作者：Jhon Lee Quint


## 1. 系统用途
此工具作为“工程工作室”（离线独立软件）开发，用于工业标签的快速原型设计和按需打印。其主要目的是允许在无需复杂设置或互联网连接的情况下，进行布局创建、条形码测试（MAC、SN、EAN）以及在 Zebra 热敏打印机上进行直接验证。

## 2. 用户手册
- **标签尺寸：**在顶部字段中设置实际尺寸（以毫米为单位，例如 100 x 150），然后点击“应用”。
- **添加元素：**使用“+ 文本”、“+ 形状”、“+ 标志/图像”按钮来构成布局。
- **条形码：**从下拉菜单中选择所需的标准。对于字母数字标准（例如包含字母的 MAC 地址），请专门使用 CODE-128 标准。像 EAN 和 UPC 这样的标准只接受数字。
- **二维码：**点击“+ 二维码”并插入所需的数据矩阵。
- **导出 (.Lab)：**“保存 .Lab”按钮导出当前项目，以供将来使用或备份布局。
- **打印（网络）：**“普通打印机”按钮生成标签的栅格化图像，并触发本机操作系统的打印管理器（非常适合联网的 A4/喷墨打印机）。
- **打印 (Zebra/WebUSB)：**通过 USB 电缆将 ZPL（Zebra 编程语言）直接发送到 Zebra 系列热敏打印机。

## 3. 技术限制和范围
作为在浏览器中离线运行的客户端应用程序，以下工程限制适用于该工具的范围：
- **缺乏批量序列化：**系统不设计用于与数据库或 ERP/MES 集成以进行自动连续打印（例如，自主打印 1,000 个连续的 MAC 地址）。操作基于单一设计 (WYSIWYG)。
- **易失性存储：**该工具没有自动保存到云或本地磁盘的功能。如果浏览器选项卡被意外关闭或刷新而未导出项目 (.Lab)，则屏幕上的数据将丢失。
- **ZPL 转换（抖动）：**对于热敏 WebUSB 打印，彩色图像和渐变会经历 Floyd-Steinberg 算法（半色调）。对比度非常低的图像在 1 位热敏打印中可能会遭受视觉质量下降。
- **WebUSB 兼容性：**通过 USB 端口直接通信需要基于 Chromium 的浏览器（Google Chrome、Microsoft Edge）。基于 Gecko 的浏览器（Mozilla Firefox）不支持此硬件 API。

## 4. 架构与使用的库
该系统建立在纯“客户端”架构（单页应用程序/单文件）之上，没有后端（服务器）依赖，确保了在隔离的工业网络（物理隔离）中的便携性和安全性。
- **核心语言：**HTML5、CSS3 和 Vanilla JavaScript (ECMAScript 6+)。
- **图形引擎 (Canvas)：**Fabric.js (v5.3.0) - 用于矢量操作、拖放操作以及在 203 DPI 物理比例下的精确渲染。
- **条形码生成：**JsBarcode (v3.11.5) - 负责数学转换和光栅化（ISO 标准）以渲染 CODE-128、EAN、UPC 等。
- **数据矩阵生成：**qrcode.js (v1.5.1) - 带有集成纠错功能的二维码矢量处理和生成。
- **物理通信 API：**原生浏览器 WebUSB API - 允许将串行字节 (ZPL/GFA 算法) 从浏览器直接路由到打印机的 USB 终结点 (Zebra Vendor ID 0x0A5F)。
